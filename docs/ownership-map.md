## How to read the columns

Two directions of flow exist, and a field uses one or the other:

- **authoring** -- a panel control writes the field and non-UI consumer code reads it. This is the direction the split is about, and the one `BROKEN` polices.
- **telemetry** -- the runtime writes the field (`scene_bridge.step`, `playback.play_cache_frame`) and a panel displays it read-only. The `stat_*` block flows this way.

- **UI writes** -- datablock the panel control edits.
- **Consumer reads** -- datablock the non-UI code reads. This is the one that decides whether an edit takes effect.
- **Runtime writes** -- datablock non-UI code *assigns*; the producing end of the telemetry direction.
- **UI reads** -- datablock a panel displays read-only (`draw_readout_grid`); the consuming end of that direction.
- **Declared: effective / authoring** -- what `pending_settings.setting_owner()` and `_authoring_owner()` currently claim.
- **`getattr` defaults** -- how many consumer reads pass a default and would therefore swallow the `AttributeError` the split is meant to raise (Phase 3).
