# PR 41 cache metadata repair

The foreign-entry guard incorrectly required a lowercase filesystem alias for
`.DS_Store` and `Thumbs.db`. On case-sensitive filesystems this prevented Free,
Move, and Rename of an otherwise managed cache. OS metadata now bypasses only
that alias check; regular-file and link checks remain mandatory. Managed cache
entries retain their canonical-name identity checks.

Six operation/metadata regressions failed before the fix and passed afterward.
The focused cache, effect-authoring, validation, workspace, unregister, Deck,
operator-panel, and viscosity-symmetry suite passed: **351 passed, 3 skipped**.
Executed on Windows with Blender 5.2 bundled Python, Warp 1.19.0, CUDA hidden,
and pytest plugin autoload disabled. The six regressions model absent lowercase
aliases; this is not a native Linux run. Three filesystem-case tests skip on
this case-insensitive Windows volume. Independent follow-up review found the
metadata issue resolved and the foreign-data/link guards retained.

Actual Blender acceptance and GPU validation remain pending.
